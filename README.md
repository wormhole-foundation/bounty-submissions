# Wormhole bug bounty submissions

This repository receives reports from the Wormhole bug bounty program. It has no code and accepts no issues or pull requests.

**To report a vulnerability, use the bug bounty portal: https://bounty.wormhole.foundation.**

The portal turns each report into a draft security advisory in this repository. Drafts are private: only the Wormhole Foundation security team and the researcher who filed the report can see them. This repository is public only because GitHub offers security advisories on public repositories alone.

Do not post vulnerability details anywhere public, including issues, discussions or pull requests here or in other Wormhole repositories.

The program terms, scope and rewards are on the portal: https://bounty.wormhole.foundation/terms.html.
